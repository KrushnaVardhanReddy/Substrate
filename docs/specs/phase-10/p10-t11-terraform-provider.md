# Phase 10 - Task 11: Official Terraform Provider

## 1. Goal
Build `terraform-provider-substrate` so DevOps teams can manage webhooks, rules, and RBAC policies entirely via Infrastructure-as-Code.

## 2. Requirements
- Implement the HashiCorp Terraform Plugin Framework in Go.
- Create resources: `substrate_webhook`, `substrate_policy`, `substrate_org`.
- Publish to the Terraform Registry.
