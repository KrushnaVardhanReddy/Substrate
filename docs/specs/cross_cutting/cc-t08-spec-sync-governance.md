# CC-T08 - Spec Sync Governance & IDE Reminders

## 1. Goal
Ensure developers updating API endpoints in code also update the corresponding `openapi.yaml` specification by enforcing it via GitHub PR templates and Substrate Custom Rules.

## 2. Requirements
1. **GitHub PR Template**: Create `.github/PULL_REQUEST_TEMPLATE.md` with a mandatory checklist for updating `openapi.yaml`.
2. **Substrate Init Scaffold**: Ensure the `substrate init` command (and any autogenerated `substrate.yaml` configs) include the `REQUIRE_SPEC_SYNC` custom rule with a commented override block.
3. **MCP Configuration Generator**: Update the MCP `generate_substrate_config` tool to output the same commented `REQUIRE_SPEC_SYNC` rule to guide AI agents.

## 3. The Custom Rule
```yaml
custom_rules:
  - id: REQUIRE_SPEC_SYNC
    description: "API handler changes must be accompanied by an openapi.yaml update."
    severity: error
    match: "commit.files.contains('api/internal/handlers/') && !commit.files.contains('openapi.yaml')"

# overrides:

#     reason: "Refactored internal DB logic; API request/response contracts remain unchanged."
#     approved_by: "team-lead-handle"
#     expires: "2026-12-31"
```
