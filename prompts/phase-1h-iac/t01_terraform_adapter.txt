═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Add Infrastructure-as-Code (Terraform) breaking-change detection to the Substrate diff engine.
Instead of parsing raw HCL, this adapter parses the JSON output of `terraform plan` 
(`terraform show -json tfplan`). It detects destructive actions on stateful resources,
removed outputs, and changes to IAM policies.

1. FILE: engine/internal/diff/terraform.go  (CREATE NEW)

   Package: package diff

   ONLY use Go stdlib: encoding/json, fmt, io, os, time, strings
   NO external dependencies.

   Internal structs (minimal required to parse the plan JSON):
   type TFResourceChange struct {
       Address string `json:"address"`
       Type    string `json:"type"`
       Name    string `json:"name"`
       Change  struct {
           Actions []string `json:"actions"`
       } `json:"change"`
   }

   type TFOutputChange struct {
       Actions []string `json:"actions"`
   }

   type TFPlan struct {
       ResourceChanges []TFResourceChange        `json:"resource_changes"`
       OutputChanges   map[string]TFOutputChange `json:"output_changes"`
   }

   Implement this function:

   func CompareTerraformPlan(planJSONPath string) (*report.DiffReport, error)

   FULL implementation flow:

   Step 1: Read planJSONPath content (raw bytes — it is JSON)
     → On read error: return error

   Step 2: Unmarshal into TFPlan struct
     → On unmarshal error: return error

   Step 3: Evaluate Resource Changes
     Iterate through plan.ResourceChanges.
     Look at the `Actions` array.
     - If Actions contains "delete" and does NOT contain "create":
       Check if it is a stateful resource. 
       Stateful types to flag: aws_dynamodb_table, aws_s3_bucket, aws_db_instance, aws_rds_cluster, google_storage_bucket.
       If it is stateful, emit 1 BREAKING change:
         RuleID: "TF_RESOURCE_DESTROYED"
         Path: resource.Address
         Severity: BREAKING
         Description: fmt.Sprintf("Stateful resource %s is marked for destruction", resource.Address)
         Recommendation: "Ensure data is backed up or state is migrated before applying."

     - If Actions contains "update" and Type is "aws_iam_policy" or "aws_iam_role_policy":
       Emit 1 WARNING change:
         RuleID: "TF_IAM_PERMISSION_REMOVED"
         Path: resource.Address
         Severity: WARNING
         Description: fmt.Sprintf("IAM policy %s is being modified. Verify no critical permissions are removed.", resource.Address)

   Step 4: Evaluate Output Changes
     Iterate through plan.OutputChanges map.
     - If Actions contains "delete":
       Emit 1 BREAKING change:
         RuleID: "TF_OUTPUT_REMOVED"
         Path: outputName
         Severity: BREAKING
         Description: fmt.Sprintf("Terraform output '%s' was removed", outputName)

   DiffReport construction:
   Always set SchemaType: "terraform-plan" and ComparedAt: time.Now().UTC().Format(time.RFC3339).

      Expected: 0 BREAKING, 1 WARNING with RuleID "TF_IAM_PERMISSION_REMOVED"
