3. FILE: github-app/src/webhook.ts
   HMAC-SHA256 signature validation and PR event parsing.

   Export: validateWebhookSignature(signature: string, body: string, secret: string): Promise<boolean>
   - Use Web Crypto API: crypto.subtle.importKey (HMAC, SHA-256) + crypto.subtle.sign
   - Constant-time comparison using crypto.subtle.verify — NOT string equality (timing attack)
   - signature input is in format "sha256=<hex>" — strip the prefix before comparing

   Export: parsePREvent(headers: Headers, body: string): PREvent | null
   - Check X-GitHub-Event header === 'pull_request'
   - Parse body as JSON
   - Only return a value for actions: opened | synchronize | reopened
   - All other events or actions: return null (Worker returns 200 immediately)

   Export interface PREvent {
     owner: string; repo: string; prNumber: number;
     headSha: string; baseBranch: string; installationId: number;
   }

4. FILE: github-app/src/github-client.ts
   GitHub API calls using the installation access token.

   a. generateInstallationToken(appId: string, privateKey: string, installationId: number): Promise<string>
      - Create RS256 JWT: header={alg:"RS256",typ:"JWT"}, payload={iss:appId, iat:now-60, exp:now+540}
      - Sign using Web Crypto: crypto.subtle.importKey (PKCS8, RSA-PSS or RSASSA-PKCS1-v1_5) + subtle.sign
      - POST to https://api.github.com/app/installations/{installationId}/access_tokens
      - Return the token string from response.token

   b. fetchFileContent(token: string, owner: string, repo: string, path: string, ref: string): Promise<string | null>
      - GET /repos/{owner}/{repo}/contents/{path}?ref={ref}
      - Decode base64 content field using atob()
      - Return null if response is 404

   c. postPRComment(token: string, owner: string, repo: string, prNumber: number, body: string): Promise<void>
      - UPSERT: GET /repos/{owner}/{repo}/issues/{prNumber}/comments first
      - If a comment by the App bot exists (check user.type === 'Bot' and body starts with '## ' + a Substrate header marker), PATCH it
      - Otherwise POST a new comment

   d. setCommitStatus(token: string, owner: string, repo: string, sha: string, state: 'success'|'failure'|'pending', description: string): Promise<void>
      - POST /repos/{owner}/{repo}/statuses/{sha}
      - Body: { state, description, context: "substrate/breaking-changes" }

5. FILE: github-app/src/index.ts
   Main Worker entry point — orchestrates everything.

   Flow (implement exactly as documented in docs/specs/github-app.md Component 1):
   Step 1:  Only accept POST → 405 otherwise
   Step 2:  Validate HMAC → 401 if invalid
