═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Svelte 5 ONLY: all state via $state, $derived, $effect runes. No legacy stores.
- Lucide icons: ALWAYS use direct imports. Example:
    import Plug from 'lucide-svelte/icons/plug'
    import Trash2 from 'lucide-svelte/icons/trash-2'
  NEVER: import { Plug } from 'lucide-svelte'  ← this causes CompileError in runes mode.
- SSE connection MUST be opened in $effect and cleaned up in its return function to
  prevent memory leaks. Pattern: const es = new EventSource(url); return () => es.close();
- Config JSON textarea MUST validate JSON on blur and show an inline error if invalid.
- The Sync Now button MUST be disabled + show a loading spinner while sync is in flight.
