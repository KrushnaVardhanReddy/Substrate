1. FILE: engine/internal/diff/proto.go  (CREATE NEW)

   Package: package diff

   Imports needed:
     "bytes"
     "encoding/json"
     "fmt"
     "os/exec"
     "strings"
     "time"
     engine/internal/report (the existing report package)

   Implement these functions:

   a. CompareProto(baseDir, headDir string) (*report.DiffReport, error)
      — Main entry point. Full implementation as per spec.

   b. mapBufType(bufType string) string
      — Returns Substrate rule ID from buf violation type.
      — Full mapping table is in docs/specs/phase-1/protobuf-checker-adapter.md.
      — Fallback: return "PROTO_" + bufType for unmapped types.

   c. mapBufSeverity(bufType string) report.ChangeSeverity
      — Returns BREAKING for all wire-break types, WARNING for package-level changes.
      — Use the severity column from the spec mapping table.
      — Default (unmapped): BREAKING.

   d. recommendationFor(bufType string) string
      — Returns a human-readable recommendation string.
      — Full recommendations are in the spec.
      — Default (unmapped): "This change breaks wire or source compatibility."

   e. slugify(s string) string
      — Replaces non-alphanumeric characters with underscores for use in IDs.
      — Example: "user/v1/user.proto" → "user_v1_user_proto"

   f. writeBufYAMLIfMissing(dir string) error
      — Writes a minimal buf.yaml to dir if one does not already exist.
      — Content: "version: v2\n"

   Internal struct (unexported):
   type bufViolation struct {
     Path        string `json:"path"`
     StartLine   int    `json:"start_line"`
     StartColumn int    `json:"start_column"`
     Type        string `json:"type"`
     Message     string `json:"message"`
   }

   FULL CompareProto() flow:
   Step 1: exec.LookPath("buf") — error if not found (include install hint)
   Step 2: writeBufYAMLIfMissing(baseDir), writeBufYAMLIfMissing(headDir)
   Step 3: exec.Command("buf", "breaking", headDir, "--against", baseDir, "--error-format", "json")
           Capture stdout + stderr separately.
   Step 4: If stderr non-empty AND stdout empty → return error (buf failed, not violations)
   Step 5: Parse stdout line by line as newline-delimited JSON bufViolation structs
   Step 6: Map each violation → report.Change using mapBufType + mapBufSeverity
   Step 7: Build report.DiffReport{SchemaType: "protobuf", ...} and return it

2. FILE: engine/internal/diff/proto_test.go  (CREATE NEW)

   Package: package diff_test  (external test package — same as openapi_test.go)

   Table-driven tests using t.Run(). All 10 test cases from the spec are MANDATORY:
   1. No changes          — 0 BREAKING, 0 WARNING
   2. Field removed       — 1 BREAKING: PROTO_FIELD_REMOVED
   3. Field type changed  — 1 BREAKING: PROTO_FIELD_TYPE_CHANGED
   4. Field number changed — 1 BREAKING: PROTO_FIELD_NUMBER_CHANGED
   5. Service removed     — 1 BREAKING: PROTO_SERVICE_REMOVED
   6. RPC method removed  — 1 BREAKING: PROTO_RPC_REMOVED
   7. Enum value removed  — 1 BREAKING: PROTO_ENUM_VALUE_REMOVED
   8. New field added     — 0 BREAKING (safe change)
   9. New RPC added       — 0 BREAKING (safe change)
   10. buf not on PATH    — error containing "buf is not installed"

   IMPORTANT for test case 10: Do NOT mock the filesystem. Instead, temporarily
   override the PATH env variable in the test to an empty string so exec.LookPath
   cannot find buf. Restore PATH after the test.

   Test helper: func protoTestdataPath(subdir string) string
   Returns the absolute path to engine/internal/diff/testdata/proto/<subdir>/

   Skip all tests (t.Skip) if buf is not installed on the test machine:
     if _, err := exec.LookPath("buf"); err != nil {
       t.Skip("buf not installed, skipping proto tests")
     }
   (Except test case 10 which tests the error path — that one must not skip)
