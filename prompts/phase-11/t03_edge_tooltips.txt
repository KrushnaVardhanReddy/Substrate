TASK: P11-T03 — Interactive Edge Tooltips

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Hovering over the dependency lines (edges) between services should reveal a tooltip detailing the exact API contract (e.g., HTTP POST, gRPC Method) that connects them.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-11/p11-t03-edge-tooltips.md

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Create a Custom Edge in Svelte Flow (`InteractiveEdge.svelte`).
- The edge must react to `onmouseenter` and `onmouseleave`.
- The floating tooltip must display mock contract details.
- Tooltip must use dark mode CSS tokens (`var(--bg-card)`, etc).

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
Edges are currently standard Svelte Flow edges. You must replace them by registering a custom edge type in `dashboard/src/routes/(app)/org/[org]/graph/+page.svelte` and implementing the custom edge component.
