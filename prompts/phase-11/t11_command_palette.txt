Implement a Raycast-style command palette overlay that allows users to instantly search for and navigate to specific microservices, teams, or settings across the enterprise graph.

CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════

- A static HTML/CSS mockup for the Command Palette modal overlay has been generated by Stitch and is located at: temp_mockups/t11_mockup.html
- Must support fuzzy search and keyboard navigation.

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
The SvelteKit dashboard lives in `dashboard/`.
The overlay component should be mounted at the root layout (`dashboard/src/routes/+layout.svelte`) so it is accessible from anywhere.
Graph nodes/metadata might need to be stored in a Svelte store so the command palette can search through them without a new network request.
