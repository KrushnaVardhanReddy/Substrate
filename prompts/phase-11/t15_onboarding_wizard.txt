CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE

The SvelteKit dashboard lives in `dashboard/`.
The wizard should be implemented as a completely standalone route (`/onboarding`) so it doesn't clutter the main dashboard view and does NOT inherit the global Sidebar.
To achieve this idiomatically in SvelteKit, you must refactor the existing routes into a `(app)` or `(dashboard)` route group, moving the root `+layout.svelte` into it, while leaving `onboarding` completely outside of it.
