TASK: P7-T00 — Zero-Config Org Rollout

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Allow enterprises to protect all repositories in their GitHub organization without 
needing to commit a `substrate.yaml` file to every single repository. Substrate 
will look for a global `substrate-org.yaml` in the `.github` repository.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-7/zero-config-org-rollout.md

═══════════════════════════════════════════════════════════════
DELIVERABLES
═══════════════════════════════════════════════════════════════

1. Diff Engine Fallback (engine/pkg/config/parser.go)
   Update parser to return a `DefaultConfig` struct when `substrate.yaml` is missing.

2. Worker Heuristics & Org Config Fetcher (github-app/src/index.ts & github-client.ts)
   - Scan PR file payloads. If known schemas (openapi.yaml, schema.graphql) are modified, auto-route to diff engine.
   - If `substrate.yaml` is NOT found in the current repo, fetch `.github/substrate-org.yaml` from the `.github` repo of the same org. Fall back to it.
   - If global config is used, default spec to `openapi.yaml`.

3. Dashboard Admin UI (Svelte dashboard)
   Add "Organization Settings" page protected by OAuth Admin scopes, with a toggle for "Enforce Substrate Globally".

4. Branch Protection Script
   Write Go logic to iterate over all repos in a GitHub Org and apply the required status check API calls when "Enforce Substrate Globally" is toggled.
