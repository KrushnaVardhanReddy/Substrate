TASK: P7-T01 — ServiceNow/Jira Dynamic CAB (Change Advisory Board)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Implement the ITSM integration for Substrate. When a breaking change is 
detected in a PR, Substrate must automatically create an Incident or Change 
Request in ServiceNow (or Jira) and dynamically extract the CODEOWNERS from 
the downstream broken repositories to add them as required approvers.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-7/p7-t01-servicenow-dynamic-cab.md

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT
═══════════════════════════════════════════════════════════════
The Registry API lives in `api/` (a Go module).
The GitHub App lives in `github-app/` (TypeScript).

Key existing files (READ ONLY — study these patterns):
  api/internal/handlers/diff.go         — Where diff reports are POSTed.
  api/internal/github/client.go         — Where GitHub API calls (like fetching CODEOWNERS) should go.
  github-app/src/formatter.ts           — Where the PR comment is constructed.

You will CREATE new files for the ITSM logic and MODIFY existing handlers to call it.

═══════════════════════════════════════════════════════════════
DELIVERABLES
═══════════════════════════════════════════════════════════════

1. FILE: api/internal/itsm/adapter.go  (CREATE NEW)
   Package: package itsm
   
   Define the Adapter interface:
   ```go
   type TicketRequest struct {
       ProviderRepo     string
       PRNumber         int
       BreakingCount    int
       ConsumersBroken  []string
       Approvers        []string
   }

   type Adapter interface {
       CreateTicket(ctx context.Context, req TicketRequest) (ticketID string, ticketURL string, err error)
   }
   ```

2. FILE: api/internal/itsm/servicenow.go (CREATE NEW)
   Implement the Adapter interface for ServiceNow.
   Requires env vars: `SERVICENOW_INSTANCE_URL`, `SERVICENOW_USERNAME`, `SERVICENOW_PASSWORD`.
   Make an HTTP POST to `/api/now/table/change_request`.

3. FILE: api/internal/itsm/jira.go (CREATE NEW)
   Implement the Adapter interface for Jira Cloud.
   Requires env vars: `JIRA_INSTANCE_URL`, `JIRA_USERNAME`, `JIRA_API_TOKEN`, `JIRA_PROJECT_KEY`.
   Make an HTTP POST to `/rest/api/3/issue`.

4. MODIFY: api/internal/handlers/diff.go
   In `SaveDiffHandler`, if the diff has breaking changes, check if ITSM is configured via env vars.
   If yes, execute the following logic:
   a. Call a new function to identify downstream broken consumers (using existing cross-repo logic).
   b. Call a new GitHub client function to fetch `.github/CODEOWNERS` or `CODEOWNERS` from those consumers.
   c. Parse the CODEOWNERS to extract approver emails/handles.
   d. Call `adapter.CreateTicket()`.
   e. Include the `ticket_url` in the JSON response payload back to the GitHub App.

5. MODIFY: github-app/src/types.ts
   Add `ticket_url?: string` to the `DiffReport` interface or the response payload from the save diff API call.

6. MODIFY: github-app/src/formatter.ts
   In `formatPRComment`, if `ticket_url` is provided in the diff response, append:
   `\n\n🎫 **CAB Ticket Created:** [View Ticket]({ticket_url})`
