OBJECTIVE
═══════════════════════════════════════════════════════════════
Replace hardcoded ITSM integrations by implementing a generic Webhook Egress system. 
Substrate will emit a standardized JSON event (`substrate.breaking_change.detected`) 
whenever a breaking change occurs. This allows enterprise teams to route events to 
their own ServiceNow, Jira, or AWS EventBridge infrastructure.

   Implement these methods in `pgstore.go`. Create a new migration file `api/migrations/003_webhooks.sql` to create the `org_webhooks` table.

2. FILE: api/internal/webhook/egress.go (CREATE NEW)
   Package: package webhook
   
   Implement the Egress Dispatcher.
   
   ```go
   type BreakingChangeEvent struct {
       EventID         string `json:"event_id"`
       EventType       string `json:"event_type"` // e.g., "substrate.breaking_change.detected"
       Timestamp       string `json:"timestamp"`
       Data            EventData `json:"data"`
   }
   
   type EventData struct {
       Organization    string `json:"organization"`
       ProviderRepo    string `json:"provider_repo"`
       PRNumber        int    `json:"pr_number,omitempty"`
       CommitSHA       string `json:"commit_sha"`
       BreakingCount   int    `json:"breaking_count"`
       BrokenConsumers []BrokenConsumer `json:"broken_consumers"`
       DiffURL         string `json:"diff_url"`
   }
   
   type BrokenConsumer struct {
       Repo       string   `json:"repo"`
       Codeowners []string `json:"codeowners"`
   }
   ```
   
   Implement `DispatchEvent(ctx context.Context, store db.Store, event BreakingChangeEvent) error`.
   This function should fetch all webhooks for `event.Data.Organization`, calculate the HMAC SHA-256 signature (if secret exists), and POST the JSON to the URLs.

3. FILE: api/internal/handlers/webhooks.go (CREATE NEW)
   Package: package handlers
   Implement the HTTP handler `RegisterWebhookHandler(store db.Store) http.HandlerFunc` to handle `POST /api/v1/org/{org}/webhooks`.

4. MODIFY: api/internal/server/router.go
   Map `POST /api/v1/org/{org}/webhooks` to the new `RegisterWebhookHandler` (protected by AuthMiddleware).

5. MODIFY: api/internal/handlers/diff.go
   In `SaveDiffHandler`, if the diff has breaking changes, you should trigger `webhook.DispatchEvent` asynchronously (in a goroutine).
   *CRITICAL REFACTOR:* To populate the `BrokenConsumers` array in the webhook payload, you must move the Cross-Repo check logic (currently exposed via `CrossRepoCheckHandler`) into an internal service function. 
   Inside `SaveDiffHandler`, after saving the diff, invoke this internal cross-repo check function to determine the blast radius, and include those results in the `BreakingChangeEvent` payload before dispatching it.
