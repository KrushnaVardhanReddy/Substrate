═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Append new `test(...)` blocks ONLY. Do NOT modify or delete the 3 existing test blocks in `graph.spec.ts`.
- The existing `beforeEach` mock data must be reused as-is. If you add a `test.describe` block, nest it inside the existing one.
- All node clicks on the Svelte Flow canvas MUST use `{ force: true }` to bypass the browser's stability/animation check, since SvelteFlow nodes are positioned absolutely and may be under transparent overlay divs.
- Do NOT hardcode pixel positions for clicks. Use CSS class selectors only.
- The graph is in "Search-First" mode: the canvas starts empty. You MUST fill the search box before asserting nodes are visible.

CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
- Graph page: `dashboard/src/routes/(app)/org/[org]/graph/+page.svelte`
- ServiceNode component: `dashboard/src/lib/components/ServiceNode.svelte`
- The `ServiceNode.svelte` template: `<div class="service-node-card {nodeType}" class:origin={data.isOrigin} class:affected={data.isAffected} class:faded={data.isFaded}>`
  - When a node is the origin (clicked): it gets `.service-node-card.origin`
  - When a node is in the blast radius: it gets `.service-node-card.affected`
  - When a node is unrelated: it gets `.service-node-card.faded`
- The icon wrapper inside each node: `<div class="icon-wrapper {nodeType}">` — so a database node has `.icon-wrapper.database`
- Edge tooltip class: `.edge-tooltip` (rendered by `InteractiveEdge.svelte` on hover)
- The mock `beforeEach` in `graph.spec.ts` sets up:
  - 1 provider: `core/auth` with `provider_metadata: { type: 'database', team: 'Platform' }`
  - 1 consumer: `frontend/dashboard` with `consumer_metadata: { type: 'frontend' }`
- The search input selector: `input.filter-input`
- SvelteFlow edge selector: `.svelte-flow__edge` or `.react-flow__edge`

IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- If `.service-node-card.faded` is not immediately visible after click, add `await page.waitForTimeout(500)` after the click to allow Svelte's reactive $derived to propagate.
- If the edge tooltip does not appear on `.hover()`, try using `page.mouse.move()` to the bounding box center of the edge element:
  ```typescript
  const edge = page.locator('.svelte-flow__edge').first();
  const box = await edge.boundingBox();
  if (box) await page.mouse.move(box.x + box.width / 2, box.y + box.height / 2);
  await expect(page.locator('.edge-tooltip')).toBeVisible({ timeout: 5000 });
  ```
- If `.svelte-flow__edge` is not found, check if the selector is `.react-flow__edge` — the XyFlow library uses both class prefixes depending on version. Inspect the DOM to confirm.
- The "affected" class on blast radius nodes is only applied when `includeNeighbors` is `true` (which is the default). Do NOT change this state.
