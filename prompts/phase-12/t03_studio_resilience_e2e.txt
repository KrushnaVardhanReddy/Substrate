1. FILE: dashboard/tests/e2e/playground.spec.ts (EXPAND — append only)

   TEST 1 — "should stream AI analysis and display findings":
   a. Mock the AI analyze endpoint to return a successful analysis payload (see Context above).
   b. `await page.goto('/playground')`.
   c. Assert the page heading contains "Playground" or "AI" or "Studio".
   d. Locate the schema editor. Try in order: `page.locator('textarea')`, `page.locator('[contenteditable="true"]')`. Fill with a broken YAML:
      ```
      openapi: 3.0.0
      info:
        title: Test API
      paths:
        /users:
          get:
            responses:
              200:
                content: {}
      ```
   e. Click the Analyze button: `page.getByRole('button', { name: /analyze/i })` or `page.locator('button:has-text("Analyze")')`.
   f. `await expect(page.locator('.analysis-result, .findings-panel, [data-testid="findings"]')).toBeVisible({ timeout: 10000 })`.
   g. Assert the result panel contains the finding text: `toContainText('BREAKING')` or `toContainText('userId')`.

   TEST 2 — "should apply auto-fix to editor content":
   a. Continuation of Test 1 setup (re-run mock + navigation).
   b. After analysis completes, click "Apply Auto-Fix": `page.getByRole('button', { name: /auto.fix/i })`.
   c. `await page.waitForTimeout(500)`.
   d. Read the current editor content:
      ```typescript
      const content = await page.locator('textarea').first().inputValue();
      ```
      or for contenteditable: `await page.locator('[contenteditable="true"]').first().innerText()`.
   e. Assert the content is NOT the original broken YAML (assert it changed).
   f. Assert no browser console error matching `$state` or `Cannot read properties`.

   TEST 3 — "should handle malformed input gracefully":
   a. Mock the analyze endpoint to return HTTP 400: `{ "error": "Invalid schema format" }`.
   b. Navigate to `/playground`.
   c. Fill the editor with intentionally broken content: `"{{ INVALID_YAML_\x00 }}"`.
   d. Click Analyze.
   e. Assert an error indicator or alert text becomes visible: `toContainText('Invalid')` or `toContainText('error')` or `page.getByRole('alert').toBeVisible()`.
   f. Assert the main playground container is still visible — page did NOT crash: `await expect(page.locator('main, .playground-container, .page-content')).toBeVisible()`.
