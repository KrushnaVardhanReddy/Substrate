OBJECTIVE

Bundle the SvelteKit static frontend, Go API binary, and Go-compiled WASM engine into a single, self-contained Docker image using a multi-stage build. Update the Makefile with a `build-prod` target and harden the GitHub Actions release pipeline to gate Docker pushes on the full test suite passing.

CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- The final Docker image MUST serve:
  - `/` → SvelteKit HTML (200 OK, text/html)
  - `/engine.wasm` → Go WASM binary (200 OK, application/wasm)
  - `/api/v1/events` → SSE stream (200 OK, text/event-stream)
- The final image MUST be under 100MB. Use `gcr.io/distroless/static-debian12` as the base.
- Do NOT change any application source code. Only touch `Dockerfile`, `Makefile`, `.github/workflows/`, and `.dockerignore`.
- The `engine.wasm` binary is built separately. Verify it already exists at `dashboard/static/engine.wasm`. If it does NOT exist, add a `build-wasm` Makefile target that compiles it.
- The GitHub Actions change MUST gate the Docker push on BOTH `go test ./...` and `npx playwright test` passing.

1. FILE: Dockerfile (CREATE or OVERWRITE)
   ```dockerfile
   # ─── Stage 1: Build SvelteKit frontend ────────────────────────────────────────
   FROM node:22-alpine AS node-builder
   WORKDIR /app/dashboard
   COPY dashboard/package*.json ./
   RUN npm ci --prefer-offline
   COPY dashboard/ ./
   RUN npm run build
   # Output: /app/dashboard/build/

   # ─── Stage 2: Build Go binary ─────────────────────────────────────────────────
   FROM golang:1.23-alpine AS go-builder
   WORKDIR /app
   COPY go.mod go.sum ./
   RUN go mod download
   COPY . .
   # Build static binary (no CGO for distroless compatibility)
   RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-w -s" -o substrate .
   # Output: /app/substrate

   # ─── Stage 3: Final minimal image ────────────────────────────────────────────
   FROM gcr.io/distroless/static-debian12
   # Copy the compiled Go API binary
   COPY --from=go-builder /app/substrate /substrate
   # Copy SvelteKit built static assets to /static (served at "/" by the Go binary)
   COPY --from=node-builder /app/dashboard/build /static
   # Copy the Go WASM binary (built separately and checked into dashboard/static/)
   COPY --from=node-builder /app/dashboard/static/engine.wasm /static/engine.wasm
   EXPOSE 8090
   ENTRYPOINT ["/substrate"]
   ```

2. FILE: Makefile (MODIFY — add new targets, do NOT remove existing ones)
   Append at the end:
   ```makefile
   # ── Phase 12: Production Build ────────────────────────────────────────────────

   build-wasm:
   	GOOS=js GOARCH=wasm go build -o dashboard/static/engine.wasm ./engine/

   ## build-frontend: Build the SvelteKit dashboard for production
   build-frontend:
   	cd dashboard && npm ci && npm run build

   ## build-prod: Full production build (WASM + Frontend + Go binary)

   	docker build -t substrate:v2 .
   ```

IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- If `main.go` does not serve static files, add this before committing the Dockerfile:
  ```go
  // Serve dashboard build output from ./static/
  staticFS := http.FileServer(http.Dir("./static"))
  router.PathPrefix("/").Handler(staticFS)  // or http.Handle("/", staticFS) for stdlib mux
  ```
  The SPA (Single Page App) needs a fallback: if a path is not found in `./static/`, serve `./static/index.html`. This is critical for SvelteKit client-side routing:
  ```go
  router.PathPrefix("/").HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
      path := filepath.Join("./static", r.URL.Path)
      if _, err := os.Stat(path); os.IsNotExist(err) {
          http.ServeFile(w, r, "./static/index.html")
          return
      }
      staticFS.ServeHTTP(w, r)
  })
  ```
- The `gcr.io/distroless/static-debian12` image has no shell, no package manager, no `ls` or `sh`. Do NOT use `RUN` commands in Stage 3.
- The `-ldflags="-w -s"` flags strip debug info and symbol tables, reducing binary size by ~30%.
- If `dashboard/static/engine.wasm` does not yet exist, run `make build-wasm` locally and commit the binary, OR add the `GOOS=js GOARCH=wasm go build` step to Stage 2 of the Dockerfile.
