═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Integrate PostHog analytics into the SvelteKit dashboard behind a strict environment variable guard so crash reports and key user events (node clicks, graph loads) are captured in production — while having absolutely zero impact on the development environment, CI, or existing Playwright tests.

Spec (READ ONLY — implement from it, never edit):

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- `trackEvent()` MUST be a silent no-op when `PUBLIC_POSTHOG_KEY` env var is absent. This protects ALL existing E2E tests.
- Do NOT install `posthog-js` as an npm package. Use the PostHog CDN snippet in `app.html` to keep the production bundle size at zero.
- The PostHog snippet in `app.html` must NOT execute unless `PUBLIC_POSTHOG_KEY` is defined at runtime. Guard it with a `if (window.__POSTHOG_KEY__)` JS check.
- The change to `+page.svelte` is ONE LINE ONLY (one `trackEvent()` call in `onnodeclick`). Do NOT refactor any surrounding logic.
- Run `npx playwright test` after your changes and confirm ALL 11 existing tests still pass.

1. FILE: dashboard/src/lib/utils/telemetry.ts (CREATE NEW)
   ```typescript
   import { browser } from '$app/environment';
   import { env } from '$env/dynamic/public';

   /**
    * Tracks a named event with optional properties.
    * This is a no-op unless PUBLIC_POSTHOG_KEY is set.
    * Telemetry MUST NEVER crash the application.
    */
   export function trackEvent(name: string, props?: Record<string, unknown>): void {
     if (!browser) return;
     if (!env.PUBLIC_POSTHOG_KEY) return;
     try {
       // posthog is loaded via CDN script tag in app.html
       // eslint-disable-next-line @typescript-eslint/no-explicit-any
       (window as any).posthog?.capture(name, props ?? {});
     } catch {
       // Silently swallow — telemetry must never crash the app
     }
   }
   ```

IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- If `$env/dynamic/public` is not accessible in `telemetry.ts` (SSR issues), use `import.meta.env.PUBLIC_POSTHOG_KEY` as a fallback.
- The `browser` guard in `telemetry.ts` is critical — SvelteKit runs modules on the server during SSR, and `window` does not exist there.
- Do NOT add `PUBLIC_POSTHOG_KEY` to `.env.local` or `.env` in this commit. Leave it unset — the no-op behavior is the default and is tested by the existing Playwright suite.
- The PostHog snippet in `app.html` is long but boilerplate — copy it exactly from https://posthog.com/docs/libraries/js (the "Script tag" method). The version above is a minified variant.
