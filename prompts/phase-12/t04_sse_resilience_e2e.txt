2. FILE: scripts/e2e/phase12_sse_test.go (EXPAND — add new test functions)

   TEST A — `TestSSEBroker_100ConcurrentClients`:
   ```
   a. broker := NewSSEBroker()
   b. go broker.Start()
   c. time.Sleep(50 * time.Millisecond) // allow Start() to initialise
   d. Register 100 client channels:
      for i := 0; i < 100; i++ {
          ch := make(chan string, 1)
          broker.newClients <- ch
      }
   e. time.Sleep(100 * time.Millisecond) // allow broker to process
   f. assert broker.Len() == 100
   ```

   TEST B — `TestSSEBroker_DisconnectNoLeak`:
   ```
   a. broker := NewSSEBroker(); go broker.Start()
   b. Register 100 clients, collect their channels in a slice.
   c. Disconnect all 100:
      for _, ch := range clients {
          broker.defunctClients <- ch
      }
   d. time.Sleep(200 * time.Millisecond)
   e. assert broker.Len() == 0
   ```

   TEST C — `TestSSEBroker_BroadcastUnderConcurrentDisconnect`:
   ```
   a. broker := NewSSEBroker(); go broker.Start()
   b. Register 50 clients.
   c. Launch 3 goroutines concurrently:
      - goroutine 1: disconnect clients[0:25] via defunctClients
      - goroutine 2: broadcast a message via broker.messages <- "test-event"
      - goroutine 3: broadcast another via broker.messages <- "test-event-2"
   d. Use a timeout: select { case <-done: // ok; case <-time.After(2*time.Second): t.Fatal("deadlock") }
   e. Assert no panic occurred.
   ```

   TEST D — `TestSSEBroker_HeartbeatTick`:
   ```
   a. broker := NewSSEBroker(); go broker.Start()
   b. ch := make(chan string, 2); broker.newClients <- ch
   c. time.Sleep(6 * time.Second) // wait for the 5s ticker
   d. received := <-ch
   e. assert strings.Contains(received, "heartbeat")
   ```

═══════════════════════════════════════════════════════════════
IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- If `broker.newClients <- ch` blocks, the broker's `Start()` goroutine is not running yet. Always add a `time.Sleep(50ms)` after launching `go broker.Start()` before sending to channels.
- The broker's channels (`newClients`, `defunctClients`, `messages`) are unbuffered. Send to them sequentially from the test goroutine to avoid race conditions.
- For Test C, use a `sync.WaitGroup` to coordinate the 3 goroutines:
  ```go
  var wg sync.WaitGroup
  wg.Add(3)
  go func() { defer wg.Done(); ... }()
  // etc.
  done := make(chan struct{})
  go func() { wg.Wait(); close(done) }()
  select {
  case <-done:
  case <-time.After(2 * time.Second):
      t.Fatal("broadcast deadlocked under concurrent disconnects")
  }
  ```
- Test D takes 6 seconds. Add `t.Parallel()` so it doesn't block the other fast tests.
