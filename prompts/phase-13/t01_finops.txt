CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE

The Registry API lives in `api/`.

Business logic should be decoupled in `api/internal/finops/`.

⚠️ CRITICAL CONTEXT: JSON SCHEMA BYTE SIZING ⚠️
Calculating the byte size of an OpenAPI schema response is non-trivial. You must recursively traverse the schema properties and estimate the byte size based on the types (e.g., `string` = 50 bytes, `integer` = 8 bytes, `boolean` = 1 byte). Implement a robust heuristic estimator in `api/internal/finops/estimator.go` rather than trying to instantiate actual JSON objects.

DELIVERABLES
═══════════════════════════════════════════════════════════════

1. CREATE: `api/internal/finops/estimator.go`
   - Implement `EstimateResponseByteSize(schema map[string]interface{}) int64`.
   - Traverse OpenAPI `properties` recursively.

2. CREATE: `api/internal/finops/calculator.go`
   - Implement `CalculateMonthlyCostDiff(baseBytes, proposedBytes int64, rps float64, costPerGB float64) float64`.
   - Math: `((proposed - base) * rps * 3600 * 730) / 1024^3 * costPerGB`.

3. CREATE: `api/internal/handlers/finops.go`
   - Implement `HandlePredictCost(w http.ResponseWriter, r *http.Request)`.
   - Accept JSON with `base_schema`, `proposed_schema`, and `endpoint_path`.

4. MODIFY: `api/internal/server/routes.go`
   - Register `POST /api/v1/finops/predict` to `HandlePredictCost`.

5. CREATE: `api/internal/finops/calculator_test.go`
   - Thoroughly test the math and the recursive schema byte estimator.
