DELIVERABLES (BACKEND)
═══════════════════════════════════════════════════════════════

   Create `AuthzMiddleware` that intercepts requests to `/api/v1/org/{org}/*` and verifies the user JWT contains the required RBAC role.

   Update the GitHub OAuth callback to fetch the user's organization memberships and embed their roles into the issued JWT.

   Check the decoded JWT role. If the user is not an `Admin`, conditionally hide the `Settings` and `Webhooks` navigation tabs.

2. MODIFY: dashboard/src/routes/[org]/settings/+page.svelte
   Add an onMount check to redirect to `/` or display a 403 screen if the user navigates directly to the URL without `Admin` rights.
