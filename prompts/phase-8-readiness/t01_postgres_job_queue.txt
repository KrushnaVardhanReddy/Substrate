TASK: P8-T01 — PostgreSQL Job Queue (River)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Offload synchronous webhook processing and AI diff generation to a Postgres-backed background job queue (`riverqueue/river`). This prevents GitHub App webhook timeouts for large repos and avoids introducing external infrastructure dependencies like Redis.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-8/p8-t01-postgres-job-queue.md

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Do NOT use Redis, RabbitMQ, or any other external message broker.
- Only use `github.com/riverqueue/river` and `github.com/riverqueue/river/riverdriver/riverpgxv5`.
- Ensure migrations cleanly create the riverqueue tables.
