⚠️ CRITICAL CONTEXT & IMPLEMENTATION TIPS ⚠️
1. MCP Protocol: The Model Context Protocol uses JSON-RPC 2.0 over standard input/output (stdio). 
2. Process Execution: Use `os/exec` to spawn the target MCP server command (e.g., `npx @smithery/cli run`).
3. JSON-RPC Handshake: You must send an `initialize` JSON-RPC request to the process stdin, wait for the response, and then send `tools/list` and `prompts/list`.
4. Diffing Logic: Capture the returned JSON tools list and compare it structurally against the "base" branch tools list (passed via DB or files). If a tool parameter was removed or a required parameter added, flag it as a breaking change (`SEVERITY_HIGH`).
5. Timeouts: Ensure the `exec.Cmd` has a context with a strict timeout (e.g., 10 seconds), so stalled MCP servers don't hang the Substrate CI pipeline.
