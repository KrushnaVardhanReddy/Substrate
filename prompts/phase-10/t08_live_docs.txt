TASK: P10-T08 — Live Documentation Generator

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
We want to allow users to instantly export their live Svelte Dependency Graph into a static Markdown document with a Mermaid.js diagram. This is critical for enterprise customers who need to copy-paste their architecture into Confluence, Notion, or GitHub RFCs.

You must build a new standalone REST endpoint in the Go backend that queries the Postgres database and returns a fully formatted Markdown/Mermaid document.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-10/p10-t08-live-docs.md

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- All logic must be contained in the Go backend API (`api/internal/`). 
- Do NOT modify any frontend Svelte code in `dashboard/`. We are only building the backend API endpoint for now.
- Do NOT modify the `engine/` or `github-app/`.
- The endpoint should be `GET /api/v1/export/docs/{org}`.

═══════════════════════════════════════════════════════════════
CONTEXT — ARCHITECTURE
═══════════════════════════════════════════════════════════════
- The Go backend uses `chi` for routing in `api/internal/router.go`.
- You can use the existing `queries.go` functions to fetch the dependencies (e.g. `db.GetDependencies(ctx, org)`).
- You will need to loop through the dependencies and generate a Mermaid `graph TD` string, combining it with Markdown headers for the final output.

═══════════════════════════════════════════════════════════════
DELIVERABLES
═══════════════════════════════════════════════════════════════
1. Create `api/internal/handlers/export.go` with a `HandleExportDocs` function.
2. In `HandleExportDocs`, fetch all nodes and edges for the organization from the database.
3. Generate a Markdown string containing a `# Substrate Architecture` header and a ` ```mermaid ` block defining the graph.
4. Modify `api/internal/router.go` to add the `r.Get("/export/docs/{org}", handlers.HandleExportDocs)` route.
