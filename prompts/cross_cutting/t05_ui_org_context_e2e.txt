═══════════════════════════════════════════════════════════════
CRITICAL AGENT/CI TESTING ENVIRONMENT NOTES (MUST READ)
═══════════════════════════════════════════════════════════════
- The Playwright tests you write will likely TIME OUT AND FAIL when you run them natively in your isolated agent container. This is expected!
- Your local container environment does NOT spin up the Go API backend or PostgreSQL database.
- Any UI interactions that fetch data from `/api/v1/...` will timeout locally.
- DO NOT use `test.skip()` or wrap assertions in silent `try/catch` blocks just because they fail in your local workspace.
- Allow the assertions to fail locally if the API is unreachable.
- Once your PR is opened, the GitHub Actions CI pipeline will run `scripts/e2e/run_full_e2e.sh`, which automatically spins up PGlite, the real Go backend, and the SvelteKit frontend together, validating your Playwright assertions against live data.
- Simply write the code according to the spec, verify it compiles/lints, and commit it!
