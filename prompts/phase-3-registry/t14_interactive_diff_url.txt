TASK: P3-T14 — Interactive Diff Viewer URL in GitHub PR Comments

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Every PR comment posted by the Substrate GitHub Worker currently ends with a
generic "Powered by Substrate" footer. This task adds a clickable
"View in Dashboard →" deep-link to the footer so engineers can navigate
directly from a GitHub PR to the Substrate Dashboard for the full diff report.

The dashboard link MUST be optional — if the `DASHBOARD_URL` env variable is
not configured in the Worker, the PR comment must render exactly as it does
today with no regression.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-3/dashboard.md   (Section 6: P3-T14)

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT
═══════════════════════════════════════════════════════════════
The GitHub App is a Cloudflare Worker written in TypeScript, located in github-app/.

Key files (READ ONLY unless specified):
  github-app/src/types.ts          — Env interface + DiffReport types (MODIFY)
  github-app/src/formatter.ts      — PR comment builder (MODIFY)
  github-app/src/index.ts          — Main Worker fetch handler (MODIFY)
  github-app/src/webhook.ts        — Webhook parser (READ ONLY)
  github-app/src/github-client.ts  — GitHub API calls (READ ONLY)
  github-app/test/index.test.ts    — Integration tests (MODIFY — add cases)

The formatter currently has 3 comment branches:
  1. breakingCount > 0  → "## 🔴 Substrate — Breaking Changes Detected"
  2. warningCount > 0   → "## 🟡 Substrate — Warnings Only"
  3. else               → "## ✅ Substrate — All Clear"

Every branch ends with the same footer string:
  `*Powered by [Substrate](https://github.com/KrushnaVardhanReddy/Substrate)*`

The `formatPRComment(report, config)` function currently takes 2 parameters.
The `Env` interface does NOT yet have `DASHBOARD_URL`.

1. MODIFY: github-app/src/types.ts

──────────────────────────────────────────────────────────────
2. MODIFY: github-app/src/formatter.ts
──────────────────────────────────────────────────────────────

Step A: Add a private helper function `formatFooter` at the TOP of the file
(before `formatPRComment`):

  function formatFooter(dashboardUrl?: string, owner?: string, repo?: string, prNumber?: number): string {
    const poweredBy = `*Powered by [Substrate](https://github.com/KrushnaVardhanReddy/Substrate)*`;
    if (dashboardUrl && owner && repo && prNumber) {
      const link = `${dashboardUrl}/diff?owner=${owner}&repo=${repo}&pr=${prNumber}`;
      return `[View in Dashboard →](${link})\n${poweredBy}`;
    }
    return poweredBy;
  }

Step B: Update the `formatPRComment` function signature to accept 3 optional
additional parameters after the existing `config` parameter:

  export function formatPRComment(
    report: DiffReport,
    config: SubstrateConfig,
    dashboardUrl?: string,
    owner?: string,
    repo?: string,
    prNumber?: number
  ): string

Step C: In all 3 branches of `formatPRComment`, replace every occurrence of:
  `*Powered by [Substrate](https://github.com/KrushnaVardhanReddy/Substrate)*`

With a call to the helper:
  `${formatFooter(dashboardUrl, owner, repo, prNumber)}`

There are exactly 3 occurrences — one in each branch (breaking, warning, all-clear).
Replace ALL 3. Do not leave any hardcoded powered-by strings.

Step D: `formatMissingConfigComment` already has its own hardcoded powered-by
footer with a setup guide link. Do NOT change it — it is correct as-is and
does not receive dashboard context.
