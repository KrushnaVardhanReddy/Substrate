2. Structure: The schema is a list of rules: `[{ path: "/v1/payments/*", rules: ["SECURITY_HEADER_MODIFIED"], reviewers: ["@myorg/api-platform"] }]`.
3. Glob Matching: Use `path.Match` or `regexp` to check if the incoming `DiffReport` anomaly paths match the `SCHEMAOWNERS` paths.
4. GitHub API: In `api/internal/github/client.go`, use the `google/go-github` client to request reviewers. The method is `client.PullRequests.RequestReviewers(ctx, owner, repo, prNumber, github.ReviewersRequest{TeamReviewers: []string{"api-platform"}})` (Note: separate User reviewers from Team reviewers).
5. Idempotency: Do not repeatedly add the same reviewers on every commit. Check if they are already requested before calling the GitHub API.
