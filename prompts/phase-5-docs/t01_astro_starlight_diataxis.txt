OBJECTIVE
═══════════════════════════════════════════════════════════════
Set up a modern documentation site for Substrate using Astro Starlight and migrate the existing monolithic `docs/USER_GUIDE.md` into a structured format following the Diátaxis framework (Tutorials, How-To Guides, Reference, and Explanation).

Spec (READ ONLY):
  docs/specs/documentation-strategy.md

Note: We are scaffolding a new Astro Starlight project in the repository root under `docs-site/`.

═══════════════════════════════════════════════════════════════
DELIVERABLES
═══════════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────────
1. SCAFFOLD ASTRO STARLIGHT
──────────────────────────────────────────────────────────────
Navigate to the repository root and run:
`npm create astro@latest docs-site -- --template starlight -y --install --no-git`

──────────────────────────────────────────────────────────────
2. MIGRATE USER_GUIDE.md TO DIÁTAXIS FRAMEWORK
──────────────────────────────────────────────────────────────
Read `docs/USER_GUIDE.md`. 
Create the following directory structure inside `docs-site/src/content/docs/` and migrate the corresponding content:
- `tutorials/`: Create `getting-started.md` (Installation, What is Substrate).
- `guides/`: Create `intentional-breaking-changes.md` (How to acknowledge an intentional breaking change using `substrate.yaml` overrides).
- `reference/`: Create `configuration.md` (`substrate.yaml` spec), `cli.md` (CLI reference), and `rules.md` (Breaking Rules Registry).
- `explanation/`: Create `contract-registry.md` (Cross-repo impact analysis) and `ai-shift-left.md` (AI remediation, playground).

Make sure to include Astro Starlight standard frontmatter (e.g., `title: "Getting Started"`) at the top of every markdown file.

──────────────────────────────────────────────────────────────
3. CONFIGURE STARLIGHT SIDEBAR
──────────────────────────────────────────────────────────────
Update `docs-site/astro.config.mjs`.
Modify the `sidebar` configuration in the `starlight` integration to include the 4 sections: Tutorials, How-To Guides, Reference, and Explanation. Map these to the newly created markdown files.

──────────────────────────────────────────────────────────────
4. VERIFY
──────────────────────────────────────────────────────────────
Run:
`cd docs-site && npm run build`
Ensure the new site builds successfully without errors.
