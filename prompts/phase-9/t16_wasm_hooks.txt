TASK: P9-T16 — WASM Git Pre-Commit Hooks

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Prevent developers from accidentally committing breaking API changes by running Substrate's diff engine locally via a `git pre-commit` hook, compiling the engine to WebAssembly (WASM) for instant execution.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-9/p9-t16-wasm-hooks.md

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- The WASM binary must execute in under 0.02s without requiring a local Go installation.
- Do NOT use CGO, SQLite, Postgres, or anything that breaks `GOOS=js GOARCH=wasm`. You must conditionally mock these away if they exist.
- The Node CLI wrapper must strictly output JSON and exit with code 1 on breaking changes.

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
The core diff engine lives in `engine/`.
The NPM wrapper will live in `packages/cli/`.

⚠️ CRITICAL CONTEXT: GO WASM JS BINDINGS ⚠️
You must import `"syscall/js"` and create a function `substrateDiff(base, head)` that reads two string arguments, parses them, runs the engine logic, and returns a JSON string. Make sure to use `js.Global().Set("substrateDiff", js.FuncOf(...))` and block the main thread with a channel `<-make(chan bool)`.
