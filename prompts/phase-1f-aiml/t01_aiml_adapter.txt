OBJECTIVE
═══════════════════════════════════════════════════════════════
Implement the AI/ML model contract diff adapter for the Substrate engine.
This adapter parses two `substrate.yaml` files containing an `ml_model` block
and detects breaking changes to the model's input/output interface contract.

This solves a unique problem: broken ML pipelines fail silently. A REST API
throws a 500 when a field is missing. A broken ML pipeline quietly trains
on wrong features for weeks. Substrate makes ML contracts visible and
enforced in CI/CD, just like OpenAPI contracts.

Spec (READ ONLY — implement from it, never edit):
  docs/specs/phase-1/aiml-adapter.md

EXACT STRUCT DEFINITIONS (copy verbatim — do not rename fields):

  type AIMLContract struct {
      Service string   `yaml:"service"`
      MLModel *MLModel `yaml:"ml_model"`
  }

  type MLModel struct {
      Name      string       `yaml:"name"`
      Version   string       `yaml:"version"`
      Framework string       `yaml:"framework"`
      Task      string       `yaml:"task"`
      Inputs    []ModelField `yaml:"inputs"`
      Outputs   []ModelField `yaml:"outputs"`
      Serving   *Serving     `yaml:"serving,omitempty"`
  }

  type ModelField struct {
      Name     string    `yaml:"name"`
      Type     string    `yaml:"type"`
      Required bool      `yaml:"required"`
      Range    []float64 `yaml:"range,omitempty"`
      Enum     []string  `yaml:"enum,omitempty"`
  }

  type Serving struct {
      Endpoint     string `yaml:"endpoint"`
      Method       string `yaml:"method"`
      InputFormat  string `yaml:"input_format"`
      OutputFormat string `yaml:"output_format"`
  }

PRIMARY FUNCTION:

  func CompareAIML(basePath, headPath string) (*report.DiffReport, error)

  Implementation flow:

  Step 1 — Parse files
    - os.ReadFile both paths
    - yaml.Unmarshal each into AIMLContract struct
    - If either file has a nil MLModel block → return error:
        "no ml_model block found in <path>"

  Step 2 — Diff Metadata
    a. Task changed:
       if base.Task != head.Task → BREAKING: AIML_TASK_CHANGED
       path: "ml_model.task", before: base.Task, after: head.Task

    b. Framework changed:
       if base.Framework != head.Framework → WARNING: AIML_FRAMEWORK_CHANGED
       path: "ml_model.framework", before: base.Framework, after: head.Framework

    c. Version major bump:
       Parse major version from SemVer string (e.g., "2.1.0" → major=2).
       If head major > base major → WARNING: AIML_VERSION_MAJOR_BUMP
       path: "ml_model.version", before: base.Version, after: head.Version

  Step 3 — Diff Inputs
    Build a map of base inputs by name. For each base input:
    a. If NOT in head → BREAKING: AIML_INPUT_REMOVED
       path: "ml_model.inputs.<name>"
    b. If type changed → BREAKING: AIML_INPUT_TYPE_CHANGED
       path: "ml_model.inputs.<name>.type"
    c. If enum value removed (value in base.Enum not in head.Enum) →
       BREAKING: AIML_INPUT_ENUM_VALUE_REMOVED
       path: "ml_model.inputs.<name>.enum"

    For each head input NOT in base:
    d. If required: true → BREAKING: AIML_INPUT_REQUIRED_ADDED
       path: "ml_model.inputs.<name>"
    e. If required: false or omitted → SAFE: AIML_INPUT_OPTIONAL_ADDED
       path: "ml_model.inputs.<name>"

    For enum values added to existing input fields:
    f. → SAFE: AIML_INPUT_ENUM_VALUE_ADDED
       path: "ml_model.inputs.<name>.enum"

  Step 4 — Diff Outputs
    Build a map of base outputs by name. For each base output:
    a. If NOT in head → BREAKING: AIML_OUTPUT_REMOVED
       path: "ml_model.outputs.<name>"
    b. If type changed → BREAKING: AIML_OUTPUT_TYPE_CHANGED
       path: "ml_model.outputs.<name>.type"
    c. If enum value removed → BREAKING: AIML_OUTPUT_ENUM_VALUE_REMOVED
       path: "ml_model.outputs.<name>.enum"
    d. If range narrowed (both have range, head[0] > base[0] OR head[1] < base[1]):
       → WARNING: AIML_OUTPUT_RANGE_NARROWED
       path: "ml_model.outputs.<name>.range"

    For each head output NOT in base:
    e. → SAFE: AIML_OUTPUT_ADDED
       path: "ml_model.outputs.<name>"

  Step 5 — Diff Serving (only if BOTH base and head have a Serving block)
    a. If endpoint changed → BREAKING: AIML_SERVING_ENDPOINT_CHANGED
    b. If method changed → BREAKING: AIML_SERVING_METHOD_CHANGED
    c. If input_format changed → BREAKING: AIML_SERVING_FORMAT_CHANGED
       Description: "Input format changed from '<base>' to '<head>'"
    d. If output_format changed → BREAKING: AIML_SERVING_FORMAT_CHANGED
       Description: "Output format changed from '<base>' to '<head>'"

  Step 6 — Build DiffReport
    Set SchemaType: "ai-model"
    Set ComparedAt: time.Now().UTC().Format(time.RFC3339)
    Populate BreakingChanges, Warnings, SafeChanges from the above steps.
    Set Summary counts accordingly.
    Set OverallSeverity based on counts:
      - breaking_count > 0 → report.SeverityBreaking
      - warning_count > 0 → report.SeverityWarning
      - safe_count > 0 → report.SeveritySafe
      - else → report.SeverityNoChanges

HELPER FUNCTIONS (define in same file):
  - parseAIMLContract(path string) (*AIMLContract, error) — reads file + unmarshals
  - parseMajorVersion(version string) int — extracts major from "X.Y.Z", returns 0 on parse error
  - containsString(slice []string, s string) bool — helper for enum diffing
