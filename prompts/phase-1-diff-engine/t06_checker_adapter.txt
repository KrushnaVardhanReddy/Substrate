  func CompareOpenAPI(basePath, revisionPath string, flattenAllOf bool) (*report.DiffReport, error)

═══════════════════════════════════════════════════════════════
CONTEXT — WHY THIS IS NEEDED
═══════════════════════════════════════════════════════════════
The current openapi.go implementation calls diff.Get() and manually inspects the raw
structural diff tree. This produces:

  FALSE POSITIVES: Any schema modification (even adding an optional field) fires
  FIELD_REMOVED as BREAKING because the code treats any SchemasDiff.Modified entry
  as breaking.

  FALSE NEGATIVES: REQUIRED_FIELD_ADDED, ENUM_VALUE_REMOVED, METHOD_REMOVED,
  PARAMETER_ADDED_REQUIRED, RESPONSE_SCHEMA_FIELD_REMOVED, and 20+ other rules from
  breaking-change-rules.md are completely undetected.

The fix is to use the oasdiff checker package (github.com/oasdiff/oasdiff/checker)
which has already been pulled in as a transitive dependency via go.mod.
